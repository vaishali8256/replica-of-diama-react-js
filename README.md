# Diama website (React + Vite)

`npm install` · `npm run dev` · `npm run build`

Where to change things:
- `src/config/site.js` – brand, nav links, footer, contact, social
- `src/config/home.js` – all home page copy, images, links
- `src/config/pages.js` – About / FAQ / Contact / policy text
- `src/data/products.json`, `blogs.json` – snapshot of diama.com.au catalog (replace with your API)
- `src/components/common` – shared Button, SectionTitle, ProductCard, Carousel, BlogCard, PageHeader
- `src/styles/index.css` – colors, fonts, spacing tokens
